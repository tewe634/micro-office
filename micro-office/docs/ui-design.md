# micro-office UI 设计文档

## 1. 文档目标

定义当前前端页面结构、导航策略、状态语义与交互规范，保证前端实现稳定且与后端契约一致。

## 2. 设计原则

- 数据优先：页面字段以后端返回为准，不在前端臆造业务字段
- 权限可见：导航与按钮展示由权限驱动
- 门户聚合：门户页以“上下文 + 聚合信息 + 可跳转细节”组织
- 低惊喜：管理台页面优先稳定、清晰、高密度

## 3. 页面结构

当前主路由：

- 登录页：`/login`
- 组织：`/org`
- 人员：`/users`
- 外部对象：`/objects`
- 产品：`/products`
- 对象门户：`/objects/:id/portal`
- 产品门户：`/products/:id/portal`
- 系统管理：`/admin/*`

## 4. 导航与权限

- 左侧菜单基于 `/users/me.menus` 渲染。
- `/org` 作为基础入口默认可见。
- 管理页通过 `/admin` 与子菜单权限控制。

## 5. 状态语义

统一状态色语义：

- 蓝：进行中 / 当前关注
- 灰：待处理 / 未开始
- 绿：完成
- 橙：风险 / 待确认
- 红：错误 / 失败 / 禁止

## 6. 门户页交互原则

- 上下文切换显式（岗位或 scope），切换时提示刷新中
- 明细跳转优先走可识别实体链接（对象、产品）
- 对不具备能力的入口展示降级态，不伪造数据

## 7. 管理台设计原则

- 配置页面以“列表 + 编辑”模式为主
- 模板编辑与预览分离
- 所有保存操作需要明确反馈

## 8. 非目标

- 不在本期引入低代码可视化拖拽编辑器
- 不在前端做复杂规则推理引擎
