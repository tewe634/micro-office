# V1.1.15 数据库拆解

## 1. 线程目标

- 基于 `mo_user_external_accounts` 收敛数据库口径。
- 判断当前结构是否已足够支持后台管理。

## 2. 表结构结论

当前表：

- `mo_user_external_accounts`

适合承载：

- 用户与第三方账号绑定

不适合承载：

- 岗位与第三方账号绑定

## 3. 必做项

### 3.1 结构确认

确认以下字段和约束可满足后台管理：

- `user_id`
- `provider`
- `corp_id`
- `external_user_id`
- `status`
- `bound_at`
- 唯一约束

### 3.2 是否需补充字段

数据库线程需评估是否还需要补充：

- 备注信息
- 解绑时间
- 解绑原因

若当前版本不需要，不强行增列。

### 3.3 校验 SQL

输出校验 SQL，至少覆盖：

- 表存在
- 关键字段存在
- 唯一约束存在
- 状态枚举符合预期

## 4. 数据库验收标准

- 明确该表是用户绑定主表
- 不新增岗位绑定表
- 结构可支撑后台管理页

## 5. 非目标

- 不改造成岗位绑定模型
- 不改 `sys_user` 主表承载外部账号
