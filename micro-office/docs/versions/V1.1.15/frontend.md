# V1.1.15 前端拆解

## 1. 线程目标

- 在“人员&组织”区域新增“外部账号绑定”管理入口。
- 界面位置靠近“岗位”tab，但语义明确属于人员。

## 2. 必做项

### 2.1 入口设计

优先方案：

- 在“组织 / 人员 / 岗位”旁新增：
  - `外部账号绑定`

### 2.2 列表页

列表至少展示：

- 用户姓名
- 所属组织
- 主岗位
- 辅助岗位
- provider
- corpId
- externalUserId（脱敏展示）
- 状态
- 绑定时间

### 2.3 编辑页 / 抽屉

至少支持：

- 选择或展示用户
- provider
- corpId
- externalUserId
- status

### 2.4 人员语义提示

页面上要明确提示：

- 这是人员外部账号绑定
- 不是岗位绑定

避免执行和使用时产生误解。

## 3. 前端验收标准

- 入口位置符合“靠近岗位 tab”的需求
- 界面表达清楚这是“人员绑定”
- 可完成查看、编辑、解绑

## 4. 重点改动文件

可能涉及：

- `frontend/src/pages/admin/*`
- `frontend/src/api/index.ts`
- 人员&组织管理页面相关路由/组件

## 5. 非目标

- 不在岗位详情页内做岗位绑定模型
- 不修改人员主表表单承载外部账号字段
