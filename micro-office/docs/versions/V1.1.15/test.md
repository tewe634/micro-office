# V1.1.15 测试拆解

## 1. 测试目标

- 验证人员外部账号绑定的列表、保存、回显、解绑。
- 验证不会误做成岗位绑定。

## 2. 核心用例

### 2.1 列表展示

- 能看到用户、组织、岗位与绑定摘要

### 2.2 新增绑定

- 正常新增一条绑定成功

### 2.3 冲突校验

- 外部账号已绑定其他用户时报错
- 用户已绑定同平台同企业账号时报错

### 2.4 解绑

- 解绑后状态更新为 `UNBOUND`

### 2.5 回归

- 人员/岗位管理主链路无回归
- 不存在岗位绑定外部账号的错误语义

## 3. 验收标准

- 绑定能力主语义是用户
- 位置可在岗位边上，但实现无岗位关系污染

## 4. 残余风险

- 如果页面文案不清，仍可能误导为岗位绑定
