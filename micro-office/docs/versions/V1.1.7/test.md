# V1.1.7 测试拆解

## 1. 测试目标

- 验证产品入口、模块职责、模板装配链路都已切到最新版本定义。
- 验证系统不再依赖旧版兼容逻辑。

## 2. 核心用例

### 2.1 首页入口

- 首页可见“卡片块定义”入口
- 首页可见对象模板新建入口
- 首页仍可按岗位生成模板

### 2.2 卡片块定义模块

- 可进入列表页
- 可进入编辑页
- 可新建、修改、启停卡片块

### 2.3 模板设计模块

- 模板设计页可引用卡片块
- 可调整顺序、启停、分区放置
- 不再出现旧 items/actions 主编辑交互

### 2.4 对象模板新建

- 客户、供应商、承运商、银行、产品、组织模板均有明确入口
- 新建后可直接进入编辑

### 2.5 最新版单路径验证

- 系统按最新结构可直接运行
- 不依赖旧版兼容 fallback
- 若旧数据未迁移，应由数据库线程修复，不要求前后端兜底通过

## 3. 验收标准

- 产品入口与职责划分符合最新定义
- 页面不存在“代码有但入口无”的隐形模块
- 不再以旧版兼容作为通过条件
