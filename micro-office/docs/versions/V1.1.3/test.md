# V1.1.3 测试拆解（工作流模板）

## 1. 目标

- 验证模板编排、状态启停、实例化、推荐规则四条主链路。

## 2. 用例清单

### 2.1 包管理
- 新建模板包 -> 查询可见
- 编辑模板包 -> 字段回显正确
- 复制模板包 -> nodes 同步复制
- 状态切换 ACTIVE/DISABLED 生效

### 2.2 节点编排
- 顺序节点保存/回显正确
- 并行分支保存/回显正确
- 非法 branch 参数被拒绝

### 2.3 推荐规则
- 命中 scene + current module 返回推荐列表
- 关闭规则后不再返回

### 2.4 实例化
- ACTIVE 模板可实例化成功
- DISABLED 模板实例化被拒绝
- 运行时节点可追溯模板来源

## 3. 通过标准

- P0：实例化主链路可用
- P1：模板编排与状态管理可用
- P2：推荐规则与回显体验可用
