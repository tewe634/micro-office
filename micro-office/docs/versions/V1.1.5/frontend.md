# V1.1.5 前端拆解

## 1. 目标

- 前端明确区分“保存节点”与“保存模板包信息”两个动作。

## 2. 必做项

### 2.1 节点保存请求收口
- `PUT /packages/{id}/nodes` 只提交 `{ nodes: [...] }`
- 节点 payload 仅保留节点字段白名单

### 2.2 UI 行为分离
- 节点编排区：保留“保存整包节点”按钮
- package 基本信息区：
  - 方案A（推荐）：只读
  - 方案B：独立“保存模板信息”按钮（调用 `PUT /packages/{id}`）

### 2.3 防误提交
- 保存节点前对 payload 执行过滤
- 调试日志里可打印被过滤字段（开发态）

## 3. 验收

- 节点保存请求体不含 package 字段
- package 保存请求体不含 nodes
- 两个保存动作互不影响
