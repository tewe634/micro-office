# V1.1.12 测试拆解

## 1. 目标

- 验证节点设计与工作流设计是否真正解耦。
- 验证工作流保存是否只依赖 `nodeGraph`。
- 验证系统不再向节点表写工作流引用副本。

## 2. 本线程要覆盖的范围

### 2.1 节点设计页

- 可独立进入节点设计页
- 可新建节点定义
- 可编辑节点基础信息
- 可编辑输入字段
- 可编辑输出字段
- 可编辑推荐模板
- 不依赖先创建工作流

### 2.2 工作流设计页

- 可从节点库中选择节点
- 可形成 `nodeGraph`
- 可保存串行结构
- 可保存并行结构
- 不存在节点字段编辑器

### 2.3 数据验证

- 工作流保存后，`mo_workflow_recommendation_packages.meta.nodeGraph` 正确
- 工作流保存不会往 `mo_workflow_recommendation_package_nodes` 新增引用副本
- 工作流详情可返回 `nodeGraph` 与对应节点定义装配结果

## 3. 重点回归

- 独立节点创建不再触发旧 package 外键错误
- 旧 `PUT /packages/{id}/nodes` 主路径是否已被替换或降级
- 同一节点被多个工作流引用时行为正确

## 4. 验收标准

- 节点定义页与工作流页职责清楚
- 工作流事实源是 `meta.nodeGraph`
- 节点事实源是节点定义表
- 本版未新增新表

## 5. 交付输出

1. 验证范围
2. 关键用例与结果
3. 问题清单
4. 是否建议关闭版本
5. 残余风险
