# V1.1.6 测试拆解

## 1. 测试目标

- 验证“块模板抽离与复用”链路可用。
- 验证存量模板兼容不回退。
- 验证块模板变更影响到所有引用模板，且风险可控。

## 2. 核心用例

### 2.1 块模板管理

- 新建“消息中心”块模板成功。
- 编辑块模板标题、dataKey、meta、动作成功。
- 块模板可启停、复制。
- 已被引用的块模板删除被明确拦截。

### 2.2 页面模板引用块

- 销售经理模板可引用“消息中心”块模板。
- 另一个岗位模板也可引用同一个“消息中心”块模板。
- 页面模板中可调整块引用排序。
- 可启停单个块引用。

### 2.3 复用生效

- 修改“消息中心”块模板标题后，两个岗位模板预览同步变化。
- 修改动作配置后，两个岗位模板预览动作同步变化。
- 页面模板不需要重新手工编辑块细节即可生效。

### 2.4 兼容回归

- 旧模板（仍使用内嵌 items）可正常：
  - 打开编辑页
  - 保存模板
  - 进入预览
- 预览接口仍稳定返回：
  - `template.sections[].blocks[]`
  - `data.blocks`

### 2.5 异常与边界

- 引用不存在的块模板：保存失败，错误信息明确。
- 引用 `INACTIVE` 块模板：按后端规则拦截或告警，行为一致。
- 块模板被多个模板引用时，引用列表能正确返回影响范围。

## 3. 执行顺序

1. 先验证数据库 migration 与种子。
2. 再验证块模板管理接口。
3. 再验证页面模板引用配置。
4. 最后做预览与兼容回归。

## 4. 验收标准

- “消息中心”块模板能在至少 2 个岗位模板中复用成功。
- 修改一次块模板，多处模板预览同步体现。
- 存量模板兼容不回退。
- 删除保护、状态保护、引用检查都有效。
