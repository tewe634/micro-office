# V1.1.4 概览（节点功能管理）

## 1. 版本目标

- 建立“节点功能管理”能力中心，统一管理节点定义、字段契约、行为配置。
- 让 V1.1.3 的模板编排从“只选模块”升级为“选模块 + 消费节点能力”。
- 维持状态模型简洁：`ACTIVE / DISABLED`。

## 2. 需求主线

1. 节点功能定义管理（基础信息 + 状态 +适用范围）。
2. 节点字段契约管理（INPUT/OUTPUT、必填、校验、默认值）。
3. 节点行为配置（指派、SLA、动作权限、触发钩子配置）。
4. 模板联动与影响评估（引用关系、禁用拦截、变更影响提示）。

## 3. In / Out

### In
- 节点功能管理后台页面与 API
- 字段契约配置能力与校验
- 行为配置（配置层）
- 模板侧联动消费与引用关系

### Out
- 不做复杂条件表达式引擎
- 不做动态脚本执行平台
- 不做历史实例批量回填
- 不重做组织权限体系

## 4. 核心原则

- 岗位口径优先，角色口径仅兼容兜底。
- 配置可追溯、可版本化、可停用。
- 变更不隐式破坏历史模板和历史实例。

## 5. 依赖顺序

1. 数据库先补齐节点功能/行为配置存储结构与约束。
2. 后端提供节点功能管理 API 与模板联动检查。
3. 前端上线功能管理页，并在模板编辑页接入联动。
4. 测试执行功能流 + 回归流 + 兼容流。

## 6. 验收口径

- 节点功能可独立管理并启停。
- 字段契约可配置且发布前可校验。
- 指派策略按岗位优先生效，角色仅兜底。
- 模板侧可见引用关系，禁用节点有拦截提示。
