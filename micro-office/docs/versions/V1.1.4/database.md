# V1.1.4 数据库拆解（节点功能管理）

## 1. 目标

- 为节点功能、字段契约、行为配置提供稳定存储结构与约束。

## 2. 必做项

### 2.1 节点功能存储
- 基于 `mo_module_definitions` 扩展或新增管理表承载功能配置头信息（按现库评估）
- 状态仅 `ACTIVE|DISABLED`
- 支持 `position_key` 优先、`role_key` 兼容

### 2.2 字段契约存储
- 复用或增强 `mo_module_fields`
- 保障 `(module_definition_id, field_key, field_scope)` 唯一
- 补充校验：field_scope/data_type/schema_meta 合法性

### 2.3 行为配置存储
- 存储指派、SLA、动作白名单、触发配置
- 建议 JSONB + 结构化关键字段混合（关键查询字段结构化）

### 2.4 引用关系与约束
- 节点功能与模板节点建立可追溯关联
- 停用节点能力时不影响历史实例，但拦截新绑定

## 3. 验收

- 数据结构可支撑前后端功能闭环。
- 关键唯一约束和状态约束生效。
- 引用关系可查询。
