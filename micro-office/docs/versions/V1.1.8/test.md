# V1.1.8 测试拆解

## 1. 测试目标

- 验证门户卡片管理页的信息语义已纠正为卡片资产视角。

## 2. 核心用例

### 2.1 列表展示

- 页面不显示 `更新时间`
- 页面不显示第二行 `code`
- `卡片块`列不出现：
  - `LEGACY_`
  - UUID 尾巴
  - 模板名拼接

### 2.2 数据语义

- 卡片块名称为独立卡片资产名
- 不再让用户感知卡片来自哪个门户模板

### 2.3 非兼容验证

- 不把“前端截断后看起来正常”视为通过
- 需要确认数据库数据本身已修正

## 3. 验收标准

- 页面语义符合“卡片管理”定位
- 没有 legacy 技术信息暴露
- 没有模板耦合信息暴露
