# V1.1.1 测试拆解

## 1. 线程目标

- 验证预览页视觉 1:1 还原、协议正确、非人岗模板可预览。

## 2. 用例矩阵

### 2.1 协议用例

- `GET /preview` 携带 query 参数成功。
- 无 query 时读取模板 `meta.previewEntity` 成功。
- 缺 `entityType/entityId`：返回 400。
- `entityType` 与 `templateType` 不一致：返回 400。
- 主体不存在：返回 404。

### 2.2 编辑页保存链路

- 预览主体变更后 1000ms 自动保存。
- 自动保存失败仅 toast 提示。
- 保存中点击预览：被阻止并提示。

### 2.3 视觉验收

- 深色驾驶舱风格与目标图一致。
- 模块结构（处理中/客户列表/日常/关系图/AI提醒）位置和层级正确。
- 调试面板默认折叠。

### 2.4 模板类型覆盖

- `PERSON_ROLE`
- `PRODUCT`
- `CUSTOMER_COMPANY`
- `SUPPLIER`
- `CARRIER`
- `BANK`
- `ORGANIZATION`

每类至少验证 1 个可预览模板。

### 2.5 响应式与交互

- 宽屏保持多列骨架。
- 窄屏不白屏，允许横向滚动且可操作。
- 本版不验证自动轮播。

## 3. 通过标准

- P0：接口与保存链路稳定，无阻断错误。
- P1：视觉达到 1:1 还原优先目标。
- P2：全模板类型预览覆盖通过。
