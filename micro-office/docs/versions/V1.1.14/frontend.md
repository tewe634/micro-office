# V1.1.14 前端拆解

## 1. 目标

- 补齐字段定义页面对 `list` 类型的专属交互。

## 2. 本线程要做的事

- 在“新建/编辑字段定义”弹窗中监听 `fieldType`。
- 当 `fieldType = list` 时，显示“列表项字段”配置区。
- 支持对子字段进行：
  - 新增
  - 编辑
  - 删除
  - 排序

## 3. 子字段表单建议

每个 list 子字段至少包含：

- `fieldKey`
- `name`
- `fieldType`
- `required`
- `sortOrder`
- `description`

首版限制：

- 子字段类型不允许再次选择 `list`

## 4. 禁止事项

- 不要把 list 子字段塞进普通字段说明文本里
- 不要做前端临时拼字符串 schema
- 不要对非 list 字段展示子字段配置区域

## 5. 交付输出

1. 已改文件清单
2. list 字段交互说明
3. 与后端契约对齐情况
4. 未解决阻塞项
