# V1.1.11 测试拆解

## 1. 测试目标

- 验证“日常条目管理”能在 Micro Office 内独立完成条目维护。
- 验证条目主数据、适用范围、聊天策略、会话绑定四层职责正确。
- 验证 block 继续通过 `daily_list` 消费条目，而不是逐条硬编码。

## 2. 核心用例

### 2.1 条目管理

- 新建“请假”条目成功
- 新建“报销”条目成功
- 编辑名称 / 排序 / 状态后列表正确更新

### 2.2 适用范围

- 指定组织可见时，仅命中对应组织用户
- 指定用户可见时，仅命中对应用户
- 无范围配置时按产品口径验证默认行为

### 2.3 聊天策略

- `BY_ENTRY_ONLY` 能打开共享群
- `BY_ENTRY_AND_USER` 能按用户打开个人群

### 2.4 block 使用

- `daily_list` block 无需改定义即可显示新增条目
- 模板页无需新增条目字段即可引用成功

### 2.5 职责边界

- Micro Office Chat 不承担条目创建
- block 管理页不出现逐条管理请假 / 报销的入口

## 3. 验收标准

- 条目创建、显示、点击打开全链路打通
- 条目管理与 block/template 管理边界清晰
- 旧 `mo_daily_entries` 不再被当作新版主路径使用

## 4. 残余风险关注

- 旧数据表与新主表的语义冲突
- 范围过滤默认行为不清
- 后端 provider 是否已完全切到新版数据源
