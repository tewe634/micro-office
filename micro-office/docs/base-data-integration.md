# micro-office 基础数据接入边界文档

## 1. 文档目标

定义基础数据事实源、系统自有数据边界和读写规则，避免线程间误改数据归属。

## 2. 总体结论

- 当前系统同时维护一部分主数据（组织/岗位/人员/对象/产品）与门户聚合逻辑。
- 权限和范围控制属于系统核心逻辑，不允许前端或脚本层“绕过判定”。
- 门户模板与运行时数据集为系统演进重点。

## 3. 关键表与语义

核心对象包括：

- `organization`
- `position`
- `sys_user`
- `user_position`
- `external_object`
- `product`
- `role_menu_permission`
- `user_menu_permission`
- `position_object_type`
- `user_object_type`

## 4. 接入与使用规则

- 前端只消费后端 API，不直接推断表结构
- 后端对外暴露业务语义字段，不泄漏不稳定存储细节
- 数据修复必须通过数据库线程评审，不允许业务线程随意改库

## 5. 常见边界错误

- 把历史下线模块当成当前事实源
- 在前端伪造缺失字段
- 在后端绕过权限/范围判定直接放量返回

## 6. 协作规则

- 契约冲突时，先更新文档再改实现
- 牵涉权限字段时，必须同步测试用例
