# micro-office 页面数据编排文档

## 1. 文档目标

定义关键页面的首屏数据、刷新触发与联动关系，保证前后端页面编排一致。

## 2. 页面清单

- 登录页
- 主数据管理页（组织/人员/对象/产品）
- 门户页（对象门户、产品门户）
- 管理页（权限、销售协同、门户模板）

## 3. 登录页

### 3.1 首屏

- 不依赖业务数据

### 3.2 提交

- `POST /api/auth/login`

### 3.3 成功后

- 拉取 `GET /api/users/me`
- 按菜单进入默认可见页面（当前前端默认 `/org`）

## 4. 主数据页

### 4.1 通用规则

- 首屏并发拉基础列表与必要 lookup
- 任何创建/编辑后回查列表或详情
- 失败态显式提示，不静默失败

## 5. 对象/产品门户

### 5.1 对象门户

- `GET /api/portal/objects/{id}`

### 5.2 产品门户

- `GET /api/portal/products/{id}`
- 可带 `scope`

### 5.3 门户共性

- 上下文切换触发重新拉取
- 切换过程展示刷新提示
- 不可访问时展示权限错误态

## 6. 管理页

- 权限页：`/api/admin/permissions*`
- 销售协同：`/api/admin/sales-collab/*`
- 门户模板：`/api/admin/portal-templates/*`

## 7. 编排约束

- 前端不得调用已下线主链路接口作为当前核心流程
- 如发现接口缺失，必须记录“页面 -> 接口 -> 字段”缺口
