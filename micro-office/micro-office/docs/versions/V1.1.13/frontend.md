# V1.1.13 前端拆解

## 1. 线程目标

- 在“日常条目管理”编辑页新增行为配置区块。
- 让运行时点击条目时，按条目行为配置决定是否先弹窗。
- 不再把前置弹窗能力放在门户卡片管理页继续扩展。

## 2. 必做项

### 2.1 条目编辑页新增“行为配置”

至少支持展示和编辑：

- 动作类型
- 是否启用前置弹窗
- 弹窗标题
- 确认按钮文案
- 字段列表

### 2.2 字段编辑能力

首版至少支持文本字段配置：

- 字段 key
- 字段标签
- 输入类型
- 必填
- 占位文案
- 最大长度
- 排序

### 2.3 运行时点击链路

- 点击 `daily_list` 中条目时，读取条目行为配置
- 若配置要求先弹窗，则渲染弹窗
- 用户确认后提交到后端
- 成功后按返回结果跳转

### 2.4 保持 block 页边界

- 门户卡片页不再作为本版主配置入口
- 不要求在 block 编辑页继续做前置弹窗增强

## 3. 前端验收标准

- 条目页可以配置行为
- 会议条目可配置并触发前置弹窗
- 运行时按条目配置生效
- block 页职责不再混淆

## 4. 重点改动文件

可能涉及：

- `frontend/src/pages/admin/daily-*`
- `frontend/src/components/admin/*`
- `frontend/src/pages/portal/*`
- `frontend/src/api/index.ts`

## 5. 非目标

- 不改 block/template 主结构
- 不做完整低代码动作编排器
- 不要求所有条目都有前置弹窗
