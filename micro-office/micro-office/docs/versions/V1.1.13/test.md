# V1.1.13 测试拆解

## 1. 测试目标

- 验证日常条目编辑页支持行为配置。
- 验证会议条目可先弹窗输入群聊主题，再创建群聊并跳转。
- 验证 block 页不是本版主配置入口，且原行为无误伤。

## 2. 核心用例

### 2.1 条目行为配置

- 条目页可保存行为配置
- 重新进入后配置可正确回显

### 2.2 前置弹窗

- 会议条目配置前置弹窗后，点击出现弹窗
- 空输入不能提交
- 合法输入可提交

### 2.3 创建群聊

- 输入群聊主题后创建成功
- 返回正确 `sessionId`
- 自动进入新群

### 2.4 回归

- 未配置弹窗的条目继续原逻辑
- `daily_list` block 无需新增行为配置即可继续使用
- 门户卡片管理页不作为本版主配置入口

## 3. 验收标准

- 条目行为配置与运行时链路打通
- 首个会议场景可用
- block 页职责边界清楚

## 4. 残余风险关注

- 条目行为配置存储是否足够结构化
- 运行时是否真正以条目配置为准
