# V1.1.12 测试拆解

## 1. 测试目标

- 验证系统支持“前置弹窗参数动作”。
- 验证首个场景“输入群聊主题后创建群聊并跳转”可用。
- 验证未使用该动作的原有条目/卡片行为不回归。

## 2. 核心用例

### 2.1 动作配置识别

- 配置为前置弹窗动作的条目，点击后出现弹窗
- 未配置的条目，继续直接执行原动作

### 2.2 表单校验

- 必填字段为空时不能提交
- 输入合法时可提交

### 2.3 首个创建群聊场景

- 输入 `session_title` 后创建成功
- 返回正确 `sessionId`
- 自动进入新群
- 群标题等于输入值

### 2.4 回归

- 原有 `open_workbench_session` 普通链路无回归
- 其他日常条目无误伤

## 3. 验收标准

- 动作系统支持前置弹窗参数能力
- 首个群聊创建场景成功
- 旧动作继续可用
- 无条目名硬编码依赖

## 4. 残余风险关注

- 动作配置结构是否足够通用
- 前端与后端字段映射是否一致
